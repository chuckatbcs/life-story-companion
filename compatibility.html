Platform compatibility

Compatibility is tested, not assumed.

The Life Story Companion is a downloadable AI skill for use inside a compatible AI assistant. C.B. Ventures does not host a project server for this product. A platform will only be called supported after the skills-only adapter has been tested for the parts of a long-form life-story project that matter on that host.

Adapters: not yet supported

What we validate

Being able to paste instructions into a chat is not enough. A supported skills-only configuration needs to behave reliably across interviewing, evidence handling, and honest use of the host's memory, files, and export features.

Interview behavior

Natural follow-ups, one question at a time, no checklist drift, and clear separation between capture, interview, archive, research, draft, and review modes.

Evidence discipline

REMEMBERED, FAMILY_LORE, DOCUMENTED, INFERRED, and UNRESOLVED remain distinct instead of being silently blended into certainty.

Host memory and files

The skill helps the buyer's AI keep chronology, people, places, sources, and open loops in the host's own memory or project files when those features exist. That is not a C.B. Ventures hosted database.

Export and portability

Where the host allows it, the method should encourage exportable notes and source files so the project is not trapped in one chat thread. Host limits will be disclosed.

What “supported” will mean

  • installation and updates are repeatable;
  • the skill activates when appropriate and stays out of unrelated work;
  • source files and transcripts are handled predictably on the host;
  • provenance and uncertainty are preserved;
  • the skill uses host memory/files for continuity where available, without claiming a Companion server;
  • export guidance matches what the host actually supports;
  • privacy and data-boundary language matches the actual host behavior;
  • known limitations are disclosed rather than hidden.

Why the caution?

A family legacy project may contain private recordings, photographs, documents, names, dates, and sensitive memories. The Companion is being designed so its workflow remains portable and its claims remain narrower than the capabilities actually tested.
