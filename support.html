Support

Help with the Companion.

The Life Story Companion is still in pre-release validation. This page is the current public support destination and will remain stable as production support channels are finalized.

Purchase and support. The Premium Skill is sold as a $49 one-time download via the availability section on the main site. There is no Companion-hosted project account. Please do not post private family recordings, transcripts, photographs, documents, credentials, payment card data, or other sensitive story material in a public support request.

Report a problem or ask a product question

Use the public Life Story Companion GitHub issue tracker for pre-release website, compatibility, documentation, and product-routing questions.

Open the support issue tracker →

The issue tracker is public. Describe the problem without including private family-story content. If a production release later requires a private customer-support channel, that channel will be added here before launch.

Compatibility questions

Check the Compatibility page first. A platform is not called supported until the skills-only adapter, host memory/file behavior, and host data boundaries have been tested. The product does not include a C.B. Ventures hosted project server.

Privacy or terms

Current pre-release disclosures are available on the Privacy page and Terms page. Production policies will be finalized before any paid public release.

What not to send through public support

  • passwords, authentication codes, API keys, or other credentials;
  • payment card information;
  • government identification numbers;
  • private recordings, transcripts, photographs, or documents;
  • sensitive personal information that is not necessary to describe the product issue.
